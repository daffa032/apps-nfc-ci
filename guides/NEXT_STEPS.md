## Selesai 11 Oktober 2026 (semua migration sudah dijalankan di DB lokal setelah backup)

Jalankan `php spark migrate --all` di staging/produksi bersama deploy kode. Urutan migration baru: 2026-10-11-120000 (`audit_events`), 130000 (status/paket template + 4 layout), 140000 (`plan_price_versions`), 150000 (`card_daily_metrics`, `card_daily_visitors`), 160000 (`card_aliases`), 170000 (caption 255 + FK galeri), 180000 (kolom sosial 500), 190000 (`template_versions`).

1. **Rate limit reset sandi, ubah keterangan galeri, sisa controller** (LOG-10, LOG-15, ARC-01). Lihat LOGIC-REVIEW.
2. **Upload**: decode + orientasi EXIF + resize + WebP q82 (LOG-08).
3. **Audit log** (AUD-01/AUD-02): `audit_events` append-only, kode aksi tetap, Ref ID pada error server; halaman Activity Logs (Super Admin) dengan filter aksi/hasil/pelaku/target/tanggal WIB. Tidak menyimpan sandi, token, URL, atau email.
4. **Master Harga Paket dan Master Templates** (Super Admin): harga boleh kosong, setiap ubah membuat versi baru di `plan_price_versions`; paket hanya bisa diaktifkan bila harga dan durasi terisi. Empat layout kartu baru (profesional, hangat, portofolio, gelap) dibangun di kode, awalnya non-aktif Pro; slot maks. 2 Basic + 6 total. Hak tema mengikuti paket periode berjalan.
5. **Statistik kunjungan Pro** (AN-01, AN-02): `/dashboard/analytics` (pilih bulan, 12 bulan terakhir) dan `/dashboard/analytics/data` (JSON, `no-store`, dipakai refresh tiap 60 detik/saat fokus). Dihitung hanya GET kartu Pro aktif; HEAD, bot dikenali, pemilik, dan staf tidak dihitung. Unik harian = HMAC harian dari IP + user agent (IP mentah tidak disimpan). Klik WhatsApp/telepon/email dicatat lewat beacon `POST /cards/{username}/events` dengan token harian. Gangguan analytics tidak membuat kartu gagal. Tampilan kartu identik piksel dengan dan tanpa pencatatan.
   - Isi `analytics.secret` di `.env` privat (string acak panjang). Tanpa secret: tayangan tetap dihitung, unik dan klik kontak tidak.
   - Pasang cron harian `php spark analytics:purge` (hapus hash > 30 hari, agregat > 12 bulan).
6. **Alias URL kartu** (LOG-14): username lama tersimpan di `card_aliases` saat staf mengganti username dan dialihkan 301; nama route reserved ditolak untuk username baru.

Berikutnya: integrasi Midtrans (checkout, notifikasi, rekonsiliasi) memakai `subscriptions` dan `plan_price_versions` yang sudah ada.

Prioritas 3–4 adalah perapian struktur. Jangan mengerjakannya sebagai refactor massal terpisah dari perubahan perilaku; kerjakan pada halaman yang sedang disentuh agar setiap langkah dapat diuji dan di-rollback.
