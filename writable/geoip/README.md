# GeoLite2 Country (deteksi bahasa awal)

Letakkan `GeoLite2-Country.mmdb` di folder ini. Folder `writable/` ditolak untuk akses web
(`writable/.htaccess`), dan berkas ini tidak boleh dimasukkan ke repository.

Cara mendapatkan dan memperbarui berkas ada di `guides/DEVELOPMENT.md` bagian GeoLite2.
Bila berkas tidak ada, aplikasi tetap berjalan dan menebak bahasa dari browser.
